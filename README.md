# Словарь русского языка на основе данных Wiktionary

В проекте собран словарь русского языка на основе данных Wiktionary.<br>
Словарь можно использовать для задач обработки текста (NLP) и анализа данных.

## Описание

В рамках работы реализован пайплайн извлечения и очистки слов из дампов Wiktionary.<br>
В результате получен список слов, пригодный для практического использования в задачах NLP.

Готовые файлы словаря доступны в репозитории. ИХ можно скачать и использовать в своих проектах.

## Структура репозитория
* rus_dict.ipynb - ноутбук с проектом
* russian_dictionary.csv - словарь русского языка (CSV)
* russian_dictionary.txt - словарь русского языка (TXT)
